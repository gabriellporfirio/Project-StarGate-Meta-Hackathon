# Generic install steps (M5 starting steps)

These are generic starting steps, not specific to any phone.

A Meta model edits this list for one phone, using the phone's facts
and the fetched Android pages. Code then checks every edited step
against docs/install-rules.md before the plan counts.

1. Reboot the phone to the bootloader.
2. Unlock the bootloader.
3. Flash the system image from the bootloader.
4. Wipe user data.
5. Reboot to the system.
